## In scope

### FR-0735 · Must
Approved users shall be able to work on the same document concurrently, including editing different fields within the platform at the same time, without overwriting one another's changes.

**Acceptance:** Given two approved users editing different fields of the same document simultaneously, when both save, then both changes are retained and neither user's work is lost.

### FR-0740 · Must
The platform shall provide tracked changes, version comparison highlighting what has changed, or an AI summary of changes since the user's last view, across all documents and fields, and shall retain multiple saved versions of an artefact (e.g. successive RFx or contract versions) for retrieval.

**Acceptance:** Given a document amended since a user last viewed it, when they reopen it, then the changes are identified by tracked changes, comparison highlighting or an AI change summary, and any prior saved version can be retrieved.

> ⚠ Open client query — see register Notes column.

### FR-0745 · Should
Users shall be able to direct the AI to amend a specific part of a field — identified by field name and paragraph number — with the AI changing only the nominated content and leaving the remainder unaltered; paragraph numbering shall be displayed within fields to support this.

**Acceptance:** Given a statement-of-work field containing eight paragraphs, when the user asks the AI to change paragraphs 2 and 7, then only those paragraphs are amended and the remaining six are byte-identical.

> ⚠ Open client query — see register Notes column.

### FR-0750 · Must
Where the AI has selected an incorrect template, the user shall be able to instruct a change of template in plain language and the AI shall re-populate the newly selected template with the applicable information.

**Acceptance:** Given a simple contract template selected in error, when the user instructs the AI to switch to the simple IT template, then the new template is applied and re-populated with the existing procurement information.
