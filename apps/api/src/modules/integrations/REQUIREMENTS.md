## In scope

### FR-0390 · Could
Where a customer operates an enterprise legal platform (e.g. HighQ, Icertis), the system shall raise an outbound matter-initiation event through an integration gateway and synchronise redlines and matter-stage updates back to the procurement record via webhook in near real time.

**Acceptance:** Given an integrated legal platform, when a matter is initiated, then the outbound event is delivered and acknowledged, and a subsequent redline or stage change in the legal platform is reflected against the procurement record without manual entry.

> ⚠ Open client query — see register Notes column.

### FR-0700 · Must
Field labels shall be configurable so that platform fields can be aligned to each customer's existing system naming conventions for both push and pull, and inbound ERP data shall be normalised to a consistent naming convention for reporting.

**Acceptance:** Given an ERP that names a field 'cost' where the platform names it 'expenditure', when the mapping is configured, then data exchanges in both directions resolve correctly and platform reporting presents a single consistent label.
