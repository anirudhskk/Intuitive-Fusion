## In scope

### FR-0590 · Must
A central procurement dashboard shall display all active procurements, their current lifecycle phase and completion indicators across every stage, updating automatically from AI conversation logs.

**Acceptance:** Given active procurements, when the dashboard is opened, then each procurement's current phase and stage completion indicators are shown, having updated automatically from conversation activity without manual status entry.

> ⚠ Open client query — see register Notes column.

### FR-0595 · Must
The platform shall provide a Gantt-chart style view for procurement-team-wide visibility of phase and status across all active procurements, with drag-and-drop schedule adjustment that automatically recalculates downstream timelines and delegate calendars.

**Acceptance:** Given a Gantt view, when a user drags a phase to a new date, then downstream phase dates and affected delegate calendar entries are recalculated automatically and the change is logged.

> ⚠ Open client query — see register Notes column.

### FR-0600 · Must

**Acceptance:** Given a division head and a team lead, when each opens their dashboard, then the division head sees all division procurements and the team lead sees only their team's, per the configured hierarchy.
